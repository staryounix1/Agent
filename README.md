# مشهد — استوديو السلسلات القصيرة

تطبيق واحد يغطّي دورة العمل كاملة لسلسلة فيديوهات قصيرة بالعربية: سلسلة ومشاريع بحالات واضحة، ثم سكريبت مقسّم لمشاهد، ثم صوت وصور لكل مشهد، ثم تركيب وترجمة وحركة، ثم تصدير ونص نشر جاهز. كل شيء يعمل داخل المتصفح ويُخزَّن في جهازك.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # tsc --noEmit + vite build إلى dist/
npm run preview  # معاينة بناء الإنتاج
```

الواجهة عربية من اليمين إلى اليسار، وتعمل من 360px حتى الشاشات الكبيرة.

## الاختبارات

```bash
npx tsc --noEmit   # فحص الأنواع
npx vitest run     # 72 اختبارًا: السكريبت، الخط الزمني، الصوت، الحماية، النسخ الاحتياطي
npm run build      # tsc + vite build
```

`.github/workflows/ci.yml` يشغّل الثلاثة على كل push وpull request.
اختبار المسار الكامل `tests/e2e/chat.spec.ts` (Playwright) اختياري ويحتاج `npx playwright install chromium` ثم `npx playwright test`.

## ما داخل التطبيق

الدخول الأول صار شاشة محادثة: الزبون يحكي مع المساعد، يختار نوع الفيديو، يطلب أفكارًا أو يكتب فكرته، يحدّد المدة، فيُعرض السكريبت مشهدًا بمشهد قابلًا للتعديل بكلام عادي («أقصر»، «مشهد 2: النص الجديد»)، ثم زر «اصنع الفيديو» يبني المشروع ويولّد بطاقة صورة لكل مشهد ويصدّر MP4 بالترجمة والموسيقى ويعطي التنزيل والعنوان والهاشتاغ. الأدوات تحت زر «الاستوديو» و«تحرير يدوي».

| الشاشة | الوظيفة |
| --- | --- |
| المشاريع | إنشاء سلسلة، وإنشاء مشروع داخل السلسلة، وحالة كل مشروع: فكرة ← سكريبت ← صوت وصور ← مونتاج ← جاهز |
| السكريبت | فكرة أو اقتراح ← سكريبت مقسّم لمشاهد، لكل مشهد نص منطوق ووصف بصري ومدة، قابل للتعديل |
| المشاهد | تحرير نص كل مشهد، تسجيل صوت أو رفعه، صورة أو فيديو من الهاتف، أو توليد فيديو عبر Grok |
| المونتاج | تركيب المشاهد، حركة الصور، ترجمة عربية/فرنسية/إنجليزية، موسيقى خلفية، تصدير MP4 أو WebM |
| النشر | نص نشر جاهز: عنوان ووصف وهاشتاغات مع أزرار نسخ بنقرة |
| الأحداث | سجل آخر التغييرات على المشروع |

## التخزين والنسخ الاحتياطي

- المشاريع والسكريبتات في `localStorage`.
- الصوت والفيديو والصور في IndexedDB، ولا تُرفع لأي خادم.
- حذف بيانات المتصفح يحذف المشاريع وملفاتها، لذلك من «الإعدادات ← مساحة الجهاز» زر **صدّر نسخة احتياطية** (ملف JSON واحد فيه المشاريع والصور والأصوات، حتى 80 ميغا) وزر **استورد نسخة** يدمج الناقص دون مسح الموجود.

## الصوت المجاني

التعليق الصوتي الافتراضي «Google صوت» لا يحتاج مفتاحًا:

- على الويب يمر عبر `api/tts.js` (ونفس المسار داخل `vite.config.ts` للتطوير) لأن Google لا يرسل ترويسات CORS. البروكسي يقسّم النص لمقاطع ويلصقها في MP3 واحد، ويحدّ الطلبات بـ40 كل عشر دقائق لكل عنوان.
- داخل APK لا يوجد خادم، فيتصل التطبيق بـGoogle مباشرة عبر `CapacitorHttp` الذي يتجاوز CORS.
- أي صوت يفشل يعود بتنويه واضح، والفيديو يخرج بلا تعليق بدل أن يتوقف.

## توليد الفيديو عبر Grok (اختياري)

المسار المجاني: ولّد المقطع في تطبيق Grok (Imagine)، نزّله، ثم ارفعه من شاشة المشاهد.

المسار المباشر داخل التطبيق يحتاج مفتاح xAI مدفوعًا:

```bash
XAI_API_KEY=...   # أو GROK_API_KEY
```

- في التطوير يقرأه `vite.config.ts` عبر الوسيط في `server/grok.js`.
- في الإنتاج يخدمه `api/grok-video.js` (Vercel serverless). أضف المتغير في إعدادات المنصة، ولا تضعه في كود الواجهة.

## حدود التصدير

- التصدير يتم عبر `MediaRecorder` داخل المتصفح، ويسجّل بالزمن الحقيقي: مقطع 45 ثانية يحتاج نحو 45 ثانية.
- أبقِ التبويب في المقدمة حتى ينتهي التصدير؛ إخفاؤه يوقف تحديث اللوحة ويُفسد التسجيل.
- يحتاج Chrome أو Edge حديثًا (دعم `captureStream` و`MediaRecorder`).
- الصيغة الأنسب تُختار تلقائيًا: MP4 (H.264) إن دعمها المتصفح، وإلا WebM.

## النشر

المشروع جاهز لـ Vercel: بناء Vite ثابت + دالة `api/grok-video.js`. لا يحتاج قاعدة بيانات ولا خادمًا دائمًا.

## نسخة أندرويد (APK)

التطبيق مغلّف بـ Capacitor، فيعمل داخل WebView مع تخزين محلي كامل (بدون إنترنت).

```bash
npm run build            # يبني الواجهة إلى dist/
npx cap sync android     # ينسخ الواجهة إلى مشروع أندرويد
cd android && ./gradlew assembleRelease   # أو assembleDebug
```

الملف الناتج: `android/app/build/outputs/apk/release/app-release.apk` (أو `.../debug/app-debug.apk`).

- يحتاج `ANDROID_HOME` إلى Android SDK (platform 35 + build-tools 35) وJDK 21.
- **توقيع الإصدار:** `android/app/build.gradle` يقرأ `android/keystore.properties` (مستثنى من git) ويوقّع release بمفتاح `android/mashhad-release.jks`. احتفظ بالمفتاح وكلماته؛ بدونهما لا تحديث للتطبيق على Google Play.
- دالتا `api/grok-video.js` و`api/tts.js` تعملان على Vercel فقط؛ داخل APK الصوت يمر عبر `CapacitorHttp` مباشرة، وباقي المسار (المحادثة، السكريبت، المونتاج، التصدير، النشر) يعمل دون خادم.
- الميكروفون والكاميرا مُصرّح بهما في `AndroidManifest.xml` لتسجيل الصوت والتقاط الصور من الهاتف.

## مزوّدون لكل مرحلة (الإعدادات)

من الشاشة «الإعدادات» تختار لكل مرحلة مزوّدها المستقل:

| المرحلة | المزوّد الافتراضي | مزوّدون جاهزون |
| --- | --- | --- |
| الفكرة والسكريبت | قوالب مدمجة (محلي) | Google AI Studio، أي خدمة متوافقة مع OpenAI، xAI، مزوّد يدوي |
| صور المشاهد | بطاقات مولّدة محليًا | Google Imagen، متوافق مع OpenAI (images)، مزوّد يدوي |
| التعليق الصوتي | Google صوت (مجاني بلا مفتاح) | ElevenLabs، Google Cloud TTS، متوافق مع OpenAI |
| الفيديو | تركيب داخل المتصفح | xAI Grok (يحتاج دالة الخادم) |

- كل مزوّد له رابط أساسي وموديل ومفتاح، وبجانب حقل المفتاح زر **تحقق** يختبر الاتصال ويعرض النتيجة تحته.
- زر «مزوّد جديد» داخل كل مرحلة يضيف مزوّدًا آخر (Google، متوافق مع OpenAI، xAI، ElevenLabs، أو رابط يدوي).
- أي مزوّد بلا مفتاح يُتجاهل، فيعود التطبيق تلقائيًا إلى المزوّد المحلي دون توقف العمل.
- المفاتيح تُخزَّن محليًا في المتصفح/التطبيق فقط (`mashhad.settings.v1`) ولا تُكتب في الكود ولا تُرفع إلى المستودع.

الواجهة في `src/views/Settings.tsx`، والسجل والتخزين في `src/lib/providers.ts`، ومحولات الطلبات في `src/lib/ai.ts`.
